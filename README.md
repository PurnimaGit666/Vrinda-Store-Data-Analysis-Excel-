# Vrinda Store Data Analysis - Excel Project

This project analyzes the sales data of Vrinda Store using MS Excel and presents the findings in an interactive dashboard.

## Tools Used
- MS Excel
- Pivot Tables
- Charts & Slicers
- Data Cleaning

## Project Overview
- Cleaned raw sales data by removing duplicates, blank values and incorrect dates
- Created Pivot Tables to analyze Month-wise Sales and Category-wise Profit
- Built an interactive dashboard to track Sales, Profit and Orders

## Key Insights
- Month with the highest sales
- Most profitable product category
- Top selling products of the store
